# Siddhi Arote — Full-Stack Java Developer Portfolio

Official full-stack engineering portfolio and Recruiter Quick-View portal for **Siddhi Arote** (Master of Computer Science, SPPU Pune | NPTEL IIT Kharagpur Elite Certified in Java).

## ✨ Key Features
- **Flagship Projects Showcase:** Restaurant Management System (Spring Boot, Spring JDBC, REST APIs, MySQL, JSP) & Online Examination System (Core Java, Servlets, JDBC, MySQL) with interactive architecture deep-dive modals.
- **Verified Academic & Certification Vault:** Built-in PDF/Image document inspector for MCS marksheets and NPTEL IIT Kharagpur & IIT Roorkee certifications.
- **Dynamic Skills Matrix:** Filterable technical competencies powered by JavaScript + JSON (`portfolio.js` + `portfolio-data.json`).
- **Recruiter Quick-View & Admin CMS:** Full Java Servlet + JSP + MySQL Admin Dashboard (`/admin`) plus static GitHub Pages / Netlify / Vercel live deployment support (`index.html`, `recruiter.html`).

## 🚀 Tech Stack
- **Backend:** Java 21, Jakarta Servlets, JSP, JDBC, MySQL 8
- **Frontend:** HTML5, CSS3, Bootstrap 5.3, JavaScript (ES5/Fetch API), JSON
